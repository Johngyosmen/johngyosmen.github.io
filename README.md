# John Gyosmen Musa Portfolio

This repository contains a static professional portfolio prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository named `johngyosmen.github.io`.
2. Upload all contents of this folder, keeping `index.html` at the repository root and the `assets` folder beside it.
3. Open the repository's **Settings**, then **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After deployment completes, open `https://johngyosmen.github.io`.

If that repository name is already used, choose another repository name and the address will be `https://johngyosmen.github.io/REPOSITORY-NAME/`.

## Local preview

Open `index.html` in a browser. For the most accurate preview, run a simple local web server from this folder.
